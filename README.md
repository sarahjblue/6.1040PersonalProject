# 6.1040 Personal Project

Welcome to my personal design project for 6.1040: Infinite Clothing. Infinite Clothing is a community-based secondhand shopping platform built for MIT students.

The link to the deployed version is here: [Deployed](https://infiniteclothing.mit-sdg.dev/)

## Building the Project

Before spinning up the application, run 'bun run check' to ensure that the application meets the design requirements as outlined in the design folder.

To build the application, run 'bun run dev'. This starts up the frontend and backend locally.
